# Biomedical Core V1 — Branded V5 Demo

Cambios V5:
- Las dos herramientas exclusivas del Super Admin aparecen juntas con tratamiento amarillo, sin texto “Super Admin”.
- Encontrar registro es sólo consulta: muestra Ver detalle, sin botones para avanzar el estado.
- Volver desde Detalle conserva la pantalla de origen; desde una búsqueda vuelve a la búsqueda con sus filtros/resultados.
- Gestionar entrega de otro usuario ahora busca por número de remito o paciente, en lugar de dropdown.
- En la gestión de otra persona sí aparecen las acciones para avanzar la entrega.
- Se corrigió el badge lateral de estado para que no se deforme.
- Al completar una entrega se puede agregar una Nota opcional.
- Las notas pueden venir precargadas en los datos demo y se muestran tanto en tarjetas como en el detalle.
