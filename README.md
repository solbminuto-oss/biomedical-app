# Biomedical Core V1 — Branded V2
Prototipo frontend, todavía sin conexión a Google Sheets.

Cambios V2:
- Navegación: Inicio / Asignado a mí / Mi cuenta.
- Dispositivo dentro de Mi cuenta.
- Eliminado Catálogo de Materiales.
- Entregas demo accionables.
- Flujo: Asignado → Registrar salida → Registrar entrega → Entregado.
- Foto de remito obligatoria en Registrar entrega.
- Remito puede capturarse con cámara o elegirse como archivo (según soporte del dispositivo/navegador).
- Estado y datos demo persisten localmente en IndexedDB.
